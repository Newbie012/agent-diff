feat(diff): a comment is written in the diff, under the line it is about, instead of in a box over it.

<details><summary>What moved</summary>

The draft opens under the last line of the selection and the code below it moves down, the way a
thread already sits under its line; a reply opens under the thread it answers. The quoted snippet is
gone, because the code it quoted is on the screen above the draft. `ctrl+s` sends and `escape`
cancels, as before. Where the diff cannot show the line, the draft still opens over the diff.

</details>
