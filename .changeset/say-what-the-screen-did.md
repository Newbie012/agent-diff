Three places where the screen did something and said nothing about it. `}` and `{` now name the edge they hit instead of absorbing the keystroke, and when a file has been widened into a single change they name the context ladder as the reason — `+` quietly trades the changes you were stepping between for the lines around them. The review panel settles and removes the comment it is standing on, so a comment the diff cannot reach — its file deleted since, or just not the file on screen — stops being one you can see but not answer. And `… N more` counts what is below it rather than every row outside the window, so scrolling to the last file no longer promises seventeen more that are not there.
