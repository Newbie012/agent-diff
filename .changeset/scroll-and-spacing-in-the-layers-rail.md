A wheel over the layers rail scrolls it. It used to walk the cursor from one file to the next and load each file's diff on the way, so one flick of a trackpad ran through the whole review and carried on for as long as the momentum lasted. The keys still move between files; the wheel now moves the view, stops at the ends, and snaps back to the file you are on the moment you press a key.

The rail's columns line up. A directory sat one column left of the layer title above it and two right of the file names below it — three ragged edges. Titles, directories and file names now step in evenly, the way the file tree already did, and a directory too long for the rail is shortened rather than cut off at the pane edge.
