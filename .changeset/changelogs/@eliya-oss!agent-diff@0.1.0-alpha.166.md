## 0.1.0-alpha.166

### Patch Changes

- feat(diff): A click moves the keys into the pane it landed in, opens the file or layer it landed on in the rail, and stands the cursor on the thread it landed on in the review panel.

- feat(review): `l` on a thread in the review panel reads it in full over the diff — the whole path, every message and the code it was written on, wrapped rather than cut — and a section counts the threads it holds whether its fold is open or shut.
